# Leaflet风场可视化 - 原始数据版本

使用Leaflet和leaflet-velocity插件创建的风场可视化项目，直接处理NetCDF转换后的原始JSON数据格式。

## 数据格式

此版本处理的是完整的NetCDF转换JSON格式：

```javascript
{
  "global_attributes": {
    "Conventions": "CF-1.0"
  },
  "variables": {
    "lon": {
      "data": [104.0, 104.1, ...], // 经度数组
      "shape": [221],
      "dims": ["nx"]
    },
    "lat": {
      "data": [14.0, 14.1, ...],   // 纬度数组
      "shape": [171],
      "dims": ["ny"]
    },
    "U10": {
      "data": [[[...]]],           // U分量数据 [时间][层][点]
      "shape": [时间, 层, 点数]
    },
    "V10": {
      "data": [[[...]]],           // V分量数据 [时间][层][点]
      "shape": [时间, 层, 点数]
    }
  }
}
```

## 运行方式

1. **启动服务器**
   ```bash
   npm start
   ```

2. **访问应用**
   打开浏览器访问: http://localhost:8080/src/leaflet-wind-v2/

## 主要特性

- **原始数据处理**: 直接解析NetCDF转换的完整JSON格式
- **动态数据解析**: 自动计算风速统计值和边界信息
- **多时间点支持**: 支持处理多个时间点的数据（如果数据包含）
- **高性能渲染**: 优化的粒子系统和Canvas渲染
- **响应式控制**: 可收起的控制面板和实时参数调节

## 数据处理流程

1. **加载原始JSON**: 从`data/output_json/outputV2.json`加载完整数据
2. **数据解析**: 提取经纬度坐标和U10/V10风场数据
3. **统计计算**: 自动计算风速范围、数据边界等统计信息
4. **格式转换**: 转换为leaflet-velocity需要的数据格式
5. **地图渲染**: 创建风场图层并设置地图边界

## 与压缩版本的区别

- **数据源**: 使用完整的NetCDF转换JSON，而非压缩的PNG+JSON格式
- **处理方式**: 直接解析数组数据，无需PNG解码
- **灵活性**: 更容易扩展支持多时间点、多层数据
- **文件大小**: 数据文件较大，但包含完整信息
