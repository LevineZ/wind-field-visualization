# Leaflet风场可视化

使用Leaflet和leaflet-velocity插件创建的风场可视化项目，以高德卫星地图作为底图。

## 运行步骤

1. **安装依赖**
   ```bash
   npm install
   ```

2. **启动本地服务器**
   ```bash
   npm start
   ```

3. **访问应用**
   打开浏览器访问: http://localhost:8080/src/leaflet-wind/

## 功能特性

- 高德卫星地图底图
- 多时间点风场数据切换
- 粒子数量和速度调节
- 风场显示/隐藏切换
- 实时风速和方向显示

## 数据格式

使用WRF模型输出的风场数据，包含：
- JSON元数据文件（包含网格信息、风速范围等）
- PNG纹理文件（R通道存储U分量，G通道存储V分量）

## 控制面板

- **时间选择**: 切换不同时间点的风场数据
- **粒子数量**: 调节显示的风场粒子密度
- **速度倍数**: 调节粒子移动速度
- **显示切换**: 显示/隐藏风场图层
